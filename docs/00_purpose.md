# 00. 目的・ストーリー・スコープ

## 目的

> **高価なフィジカル AI のハードウェアに対して、安価なコンピュータシミュレーションモデルとして、
> ガンダムから生まれた空想科学（AMBAC）が、どこまで真実に迫れるのか。**

フィジカル AI（実世界で身体を持って動く AI）は、ハードウェアが高価で試行錯誤のコストが大きい。
一方、AMBAC は「手足の質量移動の反作用で姿勢を制御する」という、フィクション発の概念である。『機動戦士ガンダム』[R1] の作品世界を支える SF 考証として、1981 年のムック本『ガンダムセンチュリー』で示されたとされる [R42]。
宇宙飛行士が手足の動きで体の向きを変えられることは古くから研究されており [R8]、宇宙飛行士の大西卓哉さんも国際宇宙ステーションで脚を使った姿勢制御に AMBAC の名を挙げている [R43, R44]。
本リポジトリでは、AMBAC を剛体力学・幾何力学・制御理論・機械学習の言葉で検証しながら、
ロボットの形状（機体の構成）が持つ意味を明らかにする。

## ストーリー

### 導入：二足歩行は本当にバランスが良いのか？　なぜ人は二本脚なのか？

AMBAC やロボット系のアニメ・ゲームでは、人型の機体が当たり前のように手足を振って姿勢を整え、二本脚で立って戦う。
しかし、二本脚は本当にバランスが良いのか。人が二本脚なのはなぜか。

**第 1 段階で得た答え**
- **静的には、二足歩行のバランスは悪い。** 足裏の支持範囲が狭く重心が高いので、10 kg の荷物を腕の先で持つだけで、
  静止していても転倒する（Sim09）。平地での安定性は戦車型の方が上である。
- **それでも立てるのは、動かせる重い上体による能動的なバランスがあるから。**
  上体を前後に傾ける腰の戦略は、手足の代わりに上体を動かす地上版の AMBAC であり、これで同じ荷物を運べるようになる（Sim09）。
  段差を上るときも、上体を前に傾けることで、膝だけでは 18 cm だった限界が 60 cm まで広がる（Sim10）。
- **人間の大きさだからこそ、脚が活きる。** 人間大の二本脚は戦車型の 2 倍以上の段差を越えるが、
  大型化すると二乗三乗則で逆転し、18 m 級の脚は 5 cm の段差しか越えられない（Sim10）。
- **条件次第で優位は入れ替わる。** 宇宙・平地・段差、人間大・巨大機で、どの形状が有利かが変わる（Sim09, 10）。
  したがって、**用途や目的に応じて形状を合わせる必要がある**（AC シリーズのアセンブルのように [R3]）。

### 第 1 段階：形状と、それが与える意味（Sim01〜10、完了）

#### 1. AMBAC の物理（宇宙）

| 問い | 答え | 出典 |
|---|---|---|
| AMBAC は物理的に成立するか | 成立する。角運動量保存の下で、手足のループ運動（幾何学的位相）により任意角の旋回が可能 | Sim01, 02 |
| 人工衛星の技術との関係は | リアクションホイールは「曲率ゼロ・連続回転できる関節」で、AMBAC の特殊な場合。運動量飽和も同じ現象 | Sim03 |
| 巨大ロボで使えるか | 回転角はスケール不変だが、速さは 1/s で落ちる。18 m 級で機敏に動くには、相似則の約 170 倍のトルクが必要 | Sim04 |
| 学習で獲得できるか | 「ループを描く振動子」という構造を与えれば可能で、専門家制御を上回った。構造なしでは失敗する | Sim05 |
| 最適制御と学習の分担は | 計画は最適制御、実行時の誤差・外乱・揺れへの対処は学習が得意 | Sim05 |

#### 2. 下半身の形状（地上）：二本脚・戦車・脚の価値

| 問い | 答え | 出典 |
|---|---|---|
| 腕を速く動かすと何が起きるか | 腕の反作用で台車が転倒・滑る。安全な最短時間は √(大きさ/重力) に比例（フルード則）。荷物を体に引き寄せる軌道で 36% 短縮 | Sim06 |
| 足は飾りか | 宇宙では飾りではない（脚は AMBAC で最も効く重い肢）。ただし推進剤を惜しまなければ飾りになる。地上の平地作業ではほぼ飾り（戦車型＋腰の方が速く安定） | Sim09 |
| 二本脚はバランスが良いか | 静的には悪い。腰の戦略（上体の前後傾）で補って初めて荷物を運べる | Sim09 |
| 段差ではどうか | 人間大では脚が戦車型の 2 倍以上。大型化すると逆転し、18 m 級の脚は 5 cm しか越えられない | Sim10 |

#### 3. 上半身、特に肩と肩甲骨：フィジカル AI に必要なスペックとトレードオフ

| 問い | 答え | 出典 |
|---|---|---|
| 3 次元の肩で何ができるか | 2 自由度の肩 1 つの円錐運動で任意の姿勢へ回れる。ただし回転の順序で結果が変わる（非可換） | Sim07 |
| 肩の座標の注意点は | 球面座標（2 軸の肩）は極の近くで関節速度が発散する（ジンバルロック） | Sim07 |
| 地上で腕を旋回させると | 接地面の狭い横方向が最も弱い。腕を下げて旋回半径と高さを減らすと 52% 短縮 | Sim07 |
| 人の肩との関係は | コッドマンのパラドックスは肩の幾何学的位相（ひねり＝腕の向きが囲んだ立体角） | Sim08 |
| 腕組みには何が必要か | ひねりを含む 3 自由度の肩と、肩甲骨による肩の付け根の移動。胸が厚いほど肩甲骨の動きが必須 | Sim08 |

**フィジカル AI として必要となるスペック**

| スペック | 根拠 |
|---|---|
| 肩は 3 自由度（ひねりを含む） | 2 軸では腕組みができず、ひねりを独立に選べない（Sim08） |
| 肩甲骨（上肢帯）に当たる、肩の付け根を動かす機構 | 腕組みに必要な内旋が人の範囲に収まる。胸の厚い機体では必須（Sim08） |
| 動かせる重い上体（腰の関節） | 二本脚の静的な不安定さを補う。段差の上りにも効く（Sim09, 10） |
| 重い下半身（宇宙で使うなら） | 脚は AMBAC で最も効く重い肢（Sim09） |
| 座標の特異点を作業範囲の外に置く設計 | ジンバルロックで関節速度が発散する（Sim07） |
| 大きさに見合ったトルク密度 | 必要トルクは大きさの 4〜5 乗、相似則で使えるトルクは 3 乗（Sim04, 10） |

**トレードオフしなければならない事象**

| トレードオフ | 内容 |
|---|---|
| 支持範囲 ↔ 段差への強さ | 戦車型は平地で安定だが段差に弱い。二本脚はその逆（Sim09, 10） |
| 機体の大きさ ↔ 機敏さ・段差 | 大きいほど遅く、脚は段差を越えられなくなる（Sim04, 06, 10） |
| 胸・装甲の厚さ ↔ 腕の可動域 | 胸が厚いほど、腕組みに必要なひねり・肩甲骨の動きが増える（Sim08） |
| 肩の自由度 ↔ 制御の複雑さ | 3 自由度にすると、経路によってひねりが勝手に変わる（コッドマンのパラドックス）ので、ひねりの計画・計測が必要（Sim08） |
| 推進剤 ↔ 時間 | スラスタは速いが推進剤を使う。AMBAC は推進剤ゼロだが遅く、周回内で大きく揺れる（Sim04, 05） |
| 重心を前に出す ↔ 後ろへの転倒 | 戦車型の段差越えで、重心の位置は必要な摩擦と転倒のしやすさを入れ替える（Sim10） |

### 第 2 段階：校正値を使った実現性の検証

組み合わせた形状（アセンブル）について、**最適な動作の校正値を定義** し、
**要求した動きや性能を実現できるか** を検証する。

```
 [形状の組み合わせ]          [シミュレーションによる評価]          [校正値]                      [実現性の検証・チューニング]
  下半身: 脚 / 戦車 / 車輪    姿勢変更能力（AMBAC, Sim03〜05, 07）   慣性パラメータ                 要求した動き・性能を満たすか
  肩の自由度・肩甲骨           転倒・滑りの限界（Sim06, 07, 09）     （AMBAC ループによる自己同定）   ・制御ゲイン
  腰・上体の可動域             段差・移動能力（Sim10）               摩擦・接触                     ・軌道最適化
  質量配分（重い脚など）        作業範囲・定格荷重（Sim07）           可動域・アクチュエータ特性        ・学習方策の制約
  アクチュエータ・大きさ・重力   人間らしい姿勢の可否（Sim08）          人の動きのデータ                ・形状の選び直し
```

1. **形状の組み合わせ**: 下半身の形式、肩の自由度、肩甲骨、腰、質量配分、アクチュエータ、大きさ、重力環境を部品として組み合わせる。
2. **シミュレーションによる評価**: 第 1 段階で作った評価を、組み合わせた機体ごとにまとめて実行し、性能表を作る。
3. **校正値の定義**: シミュレーションと実機の差を埋める値を定義する。慣性パラメータ（AMBAC ループによる自己同定）、
   摩擦・接触、可動域、アクチュエータ特性（油圧・電動）、人の動きのデータ（モーションキャプチャー）など。
4. **実現性の検証とチューニング**: 校正値を使って、要求した動き・性能（例：腕組み、段差、旋回時間、荷物運び）を実現できるかを検証する。
   満たさなければ、制御・軌道・学習方策の制約を調整し、必要なら形状を選び直す。

## スコープと前提

### 扱った環境とモデル
- **宇宙（自由浮遊）**: 外力がなく、角運動量が保存される。AMBAC の原理が最もきれいに現れる（Sim01〜05, 07, 09）。
- **地上**: 接触力・摩擦が働き、角運動量は保存されない（dL/dt = 接触モーメント）。接触力の限界（支持範囲・摩擦）を超えると転倒・滑りが起きる（Sim06, 07, 09, 10）。
- **平面モデルと 3 次元モデル**: 平面（Sim01〜06, 09, 10）、3 次元（Sim07, 08, 09 の一部）。
- **重力環境**: 地球・火星・月（Sim06, 07）。

### 前提として維持するもの
- **剛体の仮定**: 剛体リンクで扱う。
- **準静的・理想的なアクチュエータ**: 多くの評価で、関節のトルク・速度を理想的に出せると仮定している。

### 第 2 段階以降の課題として残すもの
- **アクチュエータの動特性（油圧・電動）**: 油圧駆動では、油の圧縮性（ばねのような振る舞い）、バルブの非線形性、応答遅れ・帯域制限、摩擦が加わる。
  - 人間程度の重量であれば、油圧でも電動でも駆動は十分可能と考えられる。
  - 油圧は高い圧力でトルク密度の「係数」を上げられるが、相似拡大したときの「指数」（トルク ∝ s³）は変わらない。巨大化の壁を根本的に越えるものではない（Sim04）。
  - まずは「帯域・遅れ・トルク速度制限・コンプライアンス」を持つ簡易モデルで近似し、制御・学習への影響を評価する。
- **動的な動作**: 踏み出し（ステップ戦略）、走り込み・蹴り出しによる乗り越え。
- **非剛体効果**: 柔軟体、流体（燃料の揺れ）、ケーブル張力。

## 検討中の論点：人間らしい動きの「基準値」をどこに置くか

**問い**: 人間らしい動きの実現には、機械工学的な制御理論よりモーションキャプチャー（人体運動の計測データ）の方が効果的か。
人体運動を基準値とする方が無難か。

**現時点の整理**
- **人体運動は「形（スタイル）」の手本として強い。** 自然さ・予測しやすさ・人間との協調に向く。
  Sim05 で学習の成否を分けた「構造（ループを描く振動子）」を、人間の動きから与えるという接続もありうる。
- **ただし、物理的に正しい手本とは限らない。** モーションキャプチャーが測るのは動きの形（運動学）で、力は測らない。
  AMBAC の効き方は手足の質量比で決まる（Sim01, 03）ため、質量配分の違うロボットに人間の動きをそのまま移すと、同じ動きでも胴体の回り方が変わる。
  肩のひねりは測り方で値が変わる（Sim08）。
- **性能の上限ではない。** Sim05 では、学習方策が人手で設計したループを上回った。
- **一方で、人間の動きの合理性は物理から説明できる場合がある。** 荷物を体に引き寄せる（Sim06）、腕を下げて旋回する（Sim07）、
  重い物を持つときに体を反らせる（Sim09）、段差で前かがみになる（Sim10）は、いずれも最適化が再発見した人間らしい動きである。
- **したがって有力なのは組み合わせ。** 人体運動を「目指す形」として与え、物理モデル・制御理論で「実現可能性（力・運動量・制約）」を保証し、
  学習でその間を埋める（モーションキャプチャーを手本に物理シミュレーション上で強化学習する手法 [R24] がこれに近い）。第 2 段階では、人の動きのデータを校正値の一つとして扱う。
